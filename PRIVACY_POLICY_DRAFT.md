# Skill Saga Privacy Policy — Draft for Final Review

**Last updated:** September 2026

This draft describes the intended data practices of Skill Saga. Replace the developer/contact placeholders and publish the final policy at a public HTTPS URL before Google Play submission.

## 1. What Skill Saga collects

Depending on the account and features used, Skill Saga may process:

- Name and email address used for account creation and authentication.
- Learner class, school, district and state information entered by the user.
- Learning activity such as quiz attempts, scores, accuracy, XP, Coins, badges, streaks and progress.
- Parent/teacher/learner relationship information needed for linked learning dashboards.
- Content created or assigned by authorized teachers/admins.

Skill Saga is not intended to request precise device location, contacts, microphone access or camera access for its core learning functions.

## 2. How data is used

Data is used to authenticate accounts, provide learning and quiz functionality, calculate progress and rewards, show relevant dashboards, deliver assigned work, maintain competition/leaderboard functionality where enabled, and provide account support.

## 3. Service providers

Skill Saga uses Firebase services for authentication and cloud database functionality. The production configuration currently keeps advertising, premium payment and discussion-forum features disabled unless separately enabled and reviewed.

## 4. Local storage

The app may store non-sensitive preferences and cached learning state on the device so the interface can continue to work efficiently.

## 5. Children's privacy

Skill Saga is an educational product that may be used by students. The final Play Console target-audience declaration, parental-consent approach, data practices and any social features must be configured to match the actual launch audience and applicable law. No discussion/forum feature should be enabled for child users until its moderation, reporting, blocking and adult-control requirements have been completed.

## 6. Security

Skill Saga uses Firebase Authentication and Firestore security rules to restrict account and learning data. No security system is completely risk-free; users should keep account credentials private.

## 7. Account deletion

Users can request/delete their account through the in-app account controls. The production deletion flow and any externally hosted deletion mechanism must be verified before release.

## 8. Data retention

Data is retained only as long as needed for the relevant account, learning and legal/support purposes. The final production retention schedule should be documented before launch.
