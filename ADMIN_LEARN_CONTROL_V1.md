# Skill Saga Admin — Learn Control v1

This version adds a dedicated Learn Control module to the Admin Console.

## Scope
- Curriculum records: review, add and change publication state.
- Learning materials: review, add and change publication state.
- Publication lifecycle: draft, published, unpublished.
- Learner placement metadata is stored with content so the admin layer can control where approved material belongs.
- Learner UI files are not changed by this module.
